Method

How the numbers work.

GitHub Stats reads public data from the GitHub REST API. No token, no backend, no AI summary.

What is counted

  • Public repositories owned by the account. The headline “Public repos” number matches GitHub and includes forks.
  • Stars and forks summed across original (non-fork) repositories.
  • Languages by the primary language GitHub reports for each original repository — by repository count, not lines of code.
  • Median repository age from repository creation dates.
  • Activity from public events in the last 30 or 90 days.

What is not counted

  • Private repositories and private contributions.
  • Commits and issues in repositories the account does not own.
  • Follower lists, email addresses, or anything not already public on the GitHub profile.
  • Forks in stars, language share, and repository totals. They are counted separately in the fine print.

Limits

  • Up to the 300 most recently pushed public repositories are analyzed.
  • Up to 300 public events are used for the 30- or 90-day activity chart.
  • Unauthenticated GitHub requests are limited to 60 per hour per IP.
  • Successful lookups are cached for 15 minutes. The fetched time is shown on every profile.

Corrections

GitHub is the source of truth. If something looks wrong, check the profile on GitHub first. This site is not affiliated with GitHub.
