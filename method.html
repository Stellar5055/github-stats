How the numbers work.

GitHub Stats reads public data from the GitHub REST API. No account, no backend.

What is counted

  • Public repositories owned by the account. The headline “Public repos” number matches GitHub and includes forks.
  • Stars summed across original (non-fork) repositories.
  • Languages by the primary language GitHub reports for each original repository — by repository count, not lines of code.
  • Median repository age from creation dates of original repositories.
  • Activity from public events in the last 30 or 90 days, including contributions to other repositories.

What is not counted

  • Private repositories and private contributions.
  • Full commit history or code changes. The activity chart counts public events, not commits.
  • Follower lists and email addresses.
  • Forked repositories in star, language, and repo-age figures. The headline repo count includes them; the fine print shows how many were excluded.

Limits

  • Up to the 300 most recently pushed public repositories are analyzed.
  • Up to 300 public events are used for the 30- or 90-day activity chart.
  • Unauthenticated GitHub requests are limited to 60 per hour per IP.
  • Successful lookups are cached for 15 minutes. The fetched time is shown on every profile.

GitHub is the source of truth. If something looks wrong, check the profile on GitHub.
